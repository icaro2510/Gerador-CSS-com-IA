# ⚡ Gerador de HTML e CSS com IA

Aplicação web que utiliza inteligência artificial para gerar códigos HTML e CSS a partir de uma descrição fornecida pelo usuário.

O projeto foi desenvolvido como parte dos meus estudos em desenvolvimento Front-end, com o objetivo de praticar JavaScript, manipulação do DOM, consumo de APIs e integração com inteligência artificial.

## 🚀 Funcionalidades

- Geração de HTML e CSS a partir de uma descrição
- Integração com API de inteligência artificial
- Visualização do código gerado
- Pré-visualização do resultado
- Interface responsiva

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- API REST
- Inteligência Artificial

## 📚 Conceitos praticados

- Manipulação do DOM
- Eventos em JavaScript
- `fetch`
- `async/await`
- Requisições HTTP
- Consumo de API
- Manipulação de `iframe`
- Responsividade
